# Project Overview

## Purpose
Sailing Academy website - A Next.js application for a sailing school/academy business.

## Tech Stack
- **Framework**: Next.js 16.1.6
- **React**: 19.2.3
- **Styling**: Tailwind CSS 4
- **Language**: TypeScript 5
- **Linting**: ESLint 9

## Project Structure
- `app/` - Next.js app router pages
- `components/` - Reusable React components
- `lib/` - Utility functions and libraries
- `dictionaries/` - i18n translation files
- `public/` - Static assets

## Design System
- Ocean color palette: ocean-50, ocean-100, ocean-200, ocean-300, ocean-600, ocean-700, ocean-900
- Font: Uses `font-display` for headings
- Rounded corners: rounded-xl, rounded-2xl
- Responsive breakpoints: sm, md, lg
